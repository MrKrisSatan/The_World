# Changelog

## 6.54.15 — Prestigious achievements and restored seasons

- Redesigned achievement notifications as compact gold-framed presentation
  plaques with category-coloured medals, ribbon details, restrained animation,
  and pixel-width-aware titles.
- Restored the location-and-season HUD by correcting the shipped default,
  canvas positioning, seasonal update path, and clear-weather rendering.
- Added `SEASONS` and `SEASON NOTE` to Start → QOL OPTIONS → DISPLAY.

## 6.54.14 — Start-menu QOL and notification hotfix

- Fixed Start-menu QOL values reverting because the supported host exposes no
  public runtime option setter.
- Added a shared live and persisted option adapter matching Mod Manager's event
  contract.
- Added `ACHIEVEMENT POPUPS` and `GEN 1 EXP BAR` display controls.
- Added an explicit existing-save choice for all-region or visited-only AI
  simulation.

## 6.54.13 — WX starter loader hotfix

- Fixed WX starter module resolution preventing 6.54.12 from enabling.

## 6.54.12 — Crystal, regional rivals, badges, and achievements

- Added Pokémon Crystal support.
- Added complete six-region AI badge, League, and travel progression.
- Added 632 categorized achievements and a paged 48-badge Trainer Card.
- Added World Map and regional Map Card support.
- Added DIO, OZZY, MANSON, and ASMONGOLD as configured custom rivals.
- Enforced version, region, generation-scope, and WX-aware starter policies.

For the complete historical changelog, see the changelog files bundled inside
each full release archive.
