# Contributing and bug reports

The most useful contribution is a reproducible report.

Before opening an issue:

1. Confirm the problem occurs on the latest release.
2. Perform a clean install rather than merging release directories.
3. Record whether the save is new or migrated and its previous version.
4. Test without unrelated large overhaul mods when practical.

Include the game, Gen1Recomp++ version, The World version, current region/map,
enabled mods, relevant options, exact reproduction steps, screenshots, and the
complete `lua-error.log` or error text.

Do not upload ROMs, saves containing copyrighted game data, or proprietary
assets you do not have permission to redistribute.
